Project One

WatchOS Application

I developed a fatique tracking app designed for Apple Watch, focused on making self-monitoring quick and easy for the young users. The app features a clean and minimalistic interface that allows users to log their fatique levels with a few taps. The code is private due to the developmemt being for a fatigue tracking research project. The app key features include a homepage, several question pages, local notifications, and database connection.

Project Three

Poppin' Mobile Application

As part of a four-person development team, I helped create Poppin', a mobile web application where users can post about all types of their favorite media from books and movies to music and games. Each post includes a tag feature that categorizes the media type, allowing users to filter their feed and explore content based on their interests. I led development of the Profile Page, where each user can showcase their current favorite pieces of media.
